# Gambar produk

Simpan gambar produk di folder ini dengan nama dasar persis seperti daftar berikut. Halaman katalog akan otomatis mencoba ekstensi `.jpg`, `.jpeg`, `.png`, `.webp`, lalu `.avif`; gunakan huruf kecil agar nama file konsisten.

| Produk | Nama file |
| --- | --- |
| Buah Fresh — Durian Lokal | `buah-fresh-durian-lokal.jpg` |
| Buah Fresh — Durian Premium | `buah-fresh-durian-premium.jpg` |
| Menu Favorit — Ketan | `menu-favorit-ketan.jpg` |
| Menu Favorit — Ketan fla Durian | `menu-favorit-ketan-fla-durian.jpg` |
| Menu Favorit — Es Durian | `menu-favorit-es-durian.jpg` |
| Menu Favorit — Es Campur Durian | `menu-favorit-es-campur-durian.jpg` |
| Frozen — Durian Lokal | `frozen-durian-lokal.jpg` |
| Frozen — Durian Premium | `frozen-durian-premium.jpg` |
| Frozen — Daging Durian | `frozen-daging-durian.jpg` |

Contoh: letakkan `buah-fresh-durian-lokal.jpg` di `public/assets/`. Jika foto belum ada, kartu menampilkan placeholder sampai file dengan nama yang cocok tersedia.

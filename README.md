# Deni Sumando Durian Catalogue

A static one-page catalogue, served locally with Vite.

## Run in VS Code

Open this folder in VS Code, open its terminal, then run:

```powershell
npm install
npm run dev
```

Open the local URL printed in the terminal. Stop the server with `Ctrl+C`.

## Build

```powershell
npm run build
npm run preview
```

The production site is generated in `dist/`. `node_modules/` and `dist/` are ignored by Git; commit `package.json` and `package-lock.json` so another checkout can install the same dependencies with `npm install`.
